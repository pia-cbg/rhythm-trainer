# 랜덤 리듬 연습기

16가지 한 박짜리 리듬 중 **8개를 랜덤으로 뽑아 2마디(4/4)** 로 보여주고,
설정한 **BPM**에 맞춰 **사운드폰트 샘플**로 들려주는 리듬 연습 웹앱입니다.

설치나 빌드 없이 정적 파일만으로 동작해서 GitHub Pages에 그대로 올릴 수 있습니다.

## 기능

- **랜덤 뽑기**: 16가지 리듬 중 8개를 뽑아 4×2 격자(= 2마디)로 표시 (`Space`)
- **재생**: 메트로놈 + 리듬 소리, 지금 치는 박을 하이라이트하고 진행 바로 표시 (`Enter`)
- **BPM**: 30–240, 슬라이더 / ±1 / ±5 버튼 / 직접 입력 / `↑` `↓` 키 (`Shift`는 ±5)
- **사운드폰트 소리**: 우드블록, 피아노, 마림바, 타이코 드럼, 멜로딕 톰, 신스 드럼, 아고고, 스틸 드럼 + 합성음
- **옵션**: 1마디 카운트인, 반복 재생, 반복마다 새로 뽑기, 세는 법(1 e & a) 표시, 리듬/메트로놈 볼륨 따로 조절
- **뽑기 대상 고르기**: 연습할 리듬만 골라서 뽑기 (8개 미만이면 중복 허용)
- 설정과 마지막으로 뽑은 리듬은 브라우저에 저장됨, 라이트/다크 모드, 모바일 지원

## 실행

`sounds/*.mp3`를 `fetch`로 불러오기 때문에 파일을 더블클릭(`file://`)하면 샘플 대신 합성음으로 재생됩니다.
로컬에서는 간단한 서버로 여세요.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소로 push
2. 저장소 **Settings → Pages → Build and deployment** 에서 Source를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)` 로 선택
3. 잠시 후 `https://<아이디>.github.io/<저장소이름>/` 에서 접속

## 구조

```
index.html   화면
style.css    스타일 (라이트/다크)
app.js       리듬 정의, 악보 SVG 렌더링, Web Audio 스케줄러
sounds/      FluidR3 GM 사운드폰트에서 추출한 악기별 한 음 샘플
```

- 한 박을 12틱으로 나눠 16분음표(3틱)와 셋잇단(4틱)을 모두 정수로 표현합니다.
- 악보는 이미지 없이 SVG로 직접 그립니다 (빔, 꼬리, 점, 쉼표, 셋잇단 표기).
- 소리는 Web Audio 시계 기준으로 120ms 앞까지 미리 예약해서 박이 흔들리지 않습니다.
